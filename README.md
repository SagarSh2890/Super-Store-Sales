# Super-Store-Sales-Dashboard

Project Overview

Developed an interactive Power BI dashboard to analyze the sales performance of a retail super store. The dashboard provides insights into key business metrics such as sales, profit, and quantity, helping to identify trends, top-performing product categories, and regional sales performance. It also includes sales forecasting for the next 15 days using historical sales data.


Tools & Technologies

• Power BI

• Excel Dataset

• Data Visualization

• Data Analysis


Key Features

• Interactive dashboard with KPI indicators for Total Sales, Profit, and Quantity

• Sales analysis by Segment, Category, and Sub-Category

• Monthly Sales and Profit trend analysis for performance tracking

• Visualization of Payment Modes and Shipping Modes used by customers

• State-wise sales analysis to identify top-performing regions

• 15-day sales forecasting to predict future demand



Key Insights

• Consumer segment contributes the highest share of sales.

• Office Supplies is the leading product category.

• California is the top revenue-generating state.

• Standard Class is the most preferred shipping mode.
